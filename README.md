# 🧮 Calculator Website

A simple and responsive **Calculator Web Application** built using HTML, CSS, and JavaScript. The project provides a clean interface for performing basic mathematical calculations.

## 📌 Project Overview

This Calculator Website was created as a frontend development project to practice **HTML, CSS, and JavaScript**.

The calculator allows users to enter numbers and perform common arithmetic operations through an easy-to-use interface.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal calculations
* 🧹 Clear/reset calculator
* ⌫ Delete last input
* 📱 Responsive design
* 🎨 Simple and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and responsive layout
* **JavaScript** – Calculator logic and user interactions
